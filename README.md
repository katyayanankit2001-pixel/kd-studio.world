## 🚀 Getting Started

### 1. Prerequisites
- Node.js (version 18 or higher recommended)
- npm or yarn or pnpm

### 2. Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/king-detailing-studio.git
cd king-detailing-studio
npm install
```

### 3. Development Server
Start the local Vite dev server:

```bash
npm run dev
```

Open your browser at `http://localhost:3000`.

### 4. Production Build
Generate an optimized static build:

```bash
npm run build
```

The output will be placed in the `dist/` directory, ready to deploy.

## 🌐 Deployment to GitHub Pages

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of King Detailing Studio website"
   git branch -M main
   git remote add origin https://github.com/<your-username>/king-detailing-studio.git
   git push -u origin main
   ```
2. In GitHub repository settings:
   - Navigate to **Settings** > **Pages**
   - Under **Build and deployment**, select **Deploy from a branch**
   - Select `main` branch (root `/`) or configure GitHub Actions for automated Vite builds.
